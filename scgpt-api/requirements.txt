# scGPT API – Python dependencies (Python 3.11, CUDA 12.1)
#
# Strategy:
#   - The packages WE call directly (FastAPI, Pydantic, gdown, PyYAML, etc.)
#     are pinned tightly for reproducibility.
#   - The scientific stack consumed by scGPT (scvi-tools, torchtext, scib,
#     cell-gears, orbax, jax, ...) is intentionally NOT pinned here – scGPT
#     0.2.4 carries its own (narrow) constraints and we let its resolver win.
#     Adding our own pins on top would just produce ResolutionImpossible
#     errors.
#   - The Dockerfile installs torch/torchvision/torchaudio from the CUDA 12.1
#     wheel index BEFORE this file is processed, so torch is not pinned here.
#
# Local install (Python 3.11):
#   pip install torch==2.3.1 torchvision==0.18.1 torchaudio==2.3.1 -f https://download.pytorch.org/whl/cu121
#   pip install -r requirements.txt
